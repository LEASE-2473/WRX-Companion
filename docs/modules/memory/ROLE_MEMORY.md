# 角色日记与记忆

更新：2026-10-04。本文只描述当前实现，旧阶段说明已归档。

## 页面与分工

角色记忆面板有常规、日记、自主活动、设置四页。系统四表和外部世界书在单独的系统记忆面板，见[SYSTEM_MEMORY](SYSTEM_MEMORY.md)。事件页和AI共同事件写入已停用，客观事件／约定改由系统四表维护。

- 原始聊天：messages完整保存，chat/history只在构造普通聊天上下文时选择历史。
- 日记：diaries，daily_summary为独立当日日记，chat_entry为独立指定时段或聊天技能即时日记。
- 自主活动：ai_notes，保留实际活动笔记和历史读取，外出停用；普通聊天／心跳不虚构活动。
- 外部世界书：external_memory_chunks，仍使用角色记忆向量配置，但入口在系统记忆第五页。
- shared_records只作旧非约定事件兼容；已退出界面、直接注入、冷召回和AI写入。

## 独立日记

当日生成和自动日记读取所选日的原始纯对话；指定时段生成读取该日start_time至end_time，含开始不含结束，结束可24:00。使用会话时区，同角色共享材料时汇集该角色的各会话，分支按origin_id／角色／正文去重。未知时间消息不进入指定窗口。

独立日记不受普通聊天最近N条／起始时间设置裁剪，不发送图片、情绪或搜索结果对象。正文中的真实讨论仍保留。完整材料超过模型上下文时递归分段总结再合并；普通错误不触发拆分；完整成功前不写日记。

同角色、同日、同绑定范围的每日总结更新同一记录；即时日记另行保存。AI技能append_diary_entry直接依据主模型当前实际上下文写即时感受，不代表整日独立总结。AI日记写入见[技能协议](../../reference/SKILLS.md)。

## 热、冷与向量

- 热记录直接进入聊天上下文；常规页显示文本Token估算，阈值仅提醒，不静默裁剪。
- 冷记录在向量启用且模型签名有效时参与召回，结果仍受阈值、Top N和Rerank影响。
- 向量关闭、缺失或签名不匹配时，内部日记／活动记录回到直接注入，避免同时失去两条路径；持久冷热选择不被偷偷改写。
- 外部世界书仍只能冷召回，不因向量失配自动全文注入；需重新向量化。
- 编辑内部记忆清除旧向量并恢复热区；日记auto默认满7天，成功向量化才转冷。hot／cold为手动选择，auto跟随策略。
- Rerank对全部初选候选评分后再取最终数量；供应商错误回退到向量排序。

设置当前全局，正文按角色隔离，默认角色共享，可显式会话私有。来源会话仅追溯；删除会话不自动删除已形成的记忆。

## 编辑、删除与来源

日记支持标题、正文、标签；日期、来源和任务用量由后端处理。删除日记清除正文、来源、向量及标签关系，重建未结话题缓存，并允许材料重生成。没有deleted_memories恢复副本，不提供恢复UI。

每日调度默认关闭，每5分钟检查，按会话时区在结算小时后生成前一天；同角色共享时去重，失败至少隔1小时重试。停机遗漏更早日期需手动生成。

## 文件与配置

role.py负责配置、日记生成、冷热与检索；schema.py负责显式列与旧结构迁移；role_routes.py提供HTTP；static/memory/role-memory.js/css负责面板。系统逻辑在system.py／system_schema.py。正文／来源／向量在SQLite，字段见[数据库字段](../../reference/DATABASE_FIELDS.md)。

提示词来自[app/memory/prompts](../../../app/memory/prompts)，对应关系见[PROMPTS](PROMPTS.md)。Profile统一从模型与语音选择；API读取不返回明文Key。日记／系统记忆共用角色记忆Embedding／Rerank设置。

旧事件preset与event.md目前仍是配置兼容依赖，不能只因生成停用删除文件。外部JSON向量工具不是角色SQLite记忆库，见[旧向量边界](../settings/README.md)。

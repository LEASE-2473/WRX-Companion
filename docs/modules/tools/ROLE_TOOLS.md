# 角色工具与模型调用

## 使用入口

主应用部署在有可用蓝牙的电脑上。正式运行模块完整位于 `app/tools/toy/`，使用主应用的 Python 环境，根目录 `requirements.txt` 已包含 `bleak==3.0.2`。启动主应用或打开“角色工具”仅显示卡片，不启动蓝牙后台。点击卡片“启动工具”才启动或复用本机8767子服务（`python -m app.tools.toy.service --no-browser`），之后由用户手动扫描、连接。浏览器访问主应用同源代理，不直接连接浏览器所在电脑的端口。

“收起面板”保留运行；“打开控制面板”仅展开已经启动的工具。“关闭工具”对所有角色生效：立即撤下Skill与工具权限、取消DIY并使旧请求失效，后台停止扫描和经典播放，尝试写入STOP并等待最多3秒写入确认，随后断开设备并退出服务；卸载内嵌面板以结束其轮询。停止或断开失败会保留警告，后台关闭未确认会提示重试，不把失败显示成成功。关闭后可以再次启动。主应用的状态轮询在工具关闭时只读本地状态，不调用蓝牙后台。

升级后重启主应用并刷新网页。若旧版8767后台仍在运行，请先手动退出旧后台，再从卡片启动新版；旧后台不支持shutdown接口时会显示关闭未确认。关闭工具不会关闭设备电源，实际功耗与设备状态仍以实机为准。

`Toy connection/` 仅保留本地开发、解包与研究环境，整目录忽略，不参与正式部署，也不作为主应用的代码、资源或环境来源。正式服务使用8767，与开发服务8766隔离。迁移后请重启主应用；如果设备仍被开发服务占用，先由用户在旧面板断开，再在主应用面板连接。程序不会自动抢占连接。

目录结构：`controller.py` 负责接入门控与DIY；`service.py` 负责本机面板服务及BLE调度；`protocol.py` 保存协议编码；`records.py` 将运行记录写入被忽略的 `data/toy/records/`；`resources/` 保存面板、模式与工具JSON；`skill/SKILL.md` 保存仅设备接入就绪时注入的指南。子进程日志位于 `data/toy/main-project-child.log`。本模块不在通用聊天 Skill 目录中注册。

工具全局接入：任一会话启动工具后，所有角色会话共享连接、状态、工具定义与Skill。切换角色或重新打开面板不停止DIY、不更换面板令牌；任一会话的控制可接管旧任务，停止也全局生效。普通聊天不打断运行，控制仍串行执行。手动连接／断开会使旧模型请求失效。主应用正常退出时会关闭由当前进程启动的子服务；复用的服务需手动“关闭工具”，正常退出仅取消本应用DIY并尝试停止。进程崩溃或机器断电不保证停止；软件写入确认也不代表设备物理停止的测量。

## 模型看到什么

只有普通新消息且设备连接、写入就绪时，应用为每次模型请求提供：

1. `app/tools/toy/skill/SKILL.md`：单文件技能，包含通道区别、八种模式、DIY创作示例与执行约定；本次迁移保留原有内容。
2. 原生 `tools`：原有9项工具来自 `app/tools/toy/resources/tools.json`，另加 `controller.py` 定义的 `toy_play_sequence`。
3. 当前状态快照：电量缓存、软件强度目标、经典播放状态、最近指令与DIY任务状态。

开发环境中的参考稿保留作本地来源，实际应用只加载上述技能，无需读取研究文档。实际帧数组由运行模块内的播放器持有，不自动注入模型上下文。身体感受描述不是设备测量结果。

未连接、尚未全局打开工具与主动消息不获得设备工具。各角色的普通新消息共享已就绪连接；重新生成／编辑重发仍读取Skill，但仅开放toy_get_state，避免重复动作，真实控制请发送新消息。记忆技能导致额外模型续轮时会重新检查连接；设备工具已执行后，本轮后续记忆续轮不再执行设备工具。

## 模型输出什么

普通回复输出 `content`；操作通过 OpenAI-compatible 原生 `tool_calls` 输出函数名与JSON参数。一轮最多一个设备调用，应用只在工具流完整结束、参数校验通过后执行。不从正文抓取代码，不运行Python或Shell；记忆技能原有XML协议与设备调用分开。

执行状态通过SSE发送到界面，写入请求追踪；Skill要求调用工具同时输出聊天正文；若只有工具结果而无正文，应用携执行结果补写一次，禁用工具与自动重试。有正文不追加；补写仍为空则报错并保留原消息，不把空正文算成功。模型当前回复尚未看到本次执行结果，不能提前声称成功；下一轮设备快照提供最新状态。记忆读取、联网判断等既有功能仍可能增加模型请求次数。供应商必须支持原生流式tools，不支持时显示错误，不偷偷回退成正文命令。

## DIY序列

`toy_play_sequence` 参数：`frames` 为1–256组三整数目标，每项0或15–100；`frame_ms` 为65–10000整数；`duration_seconds` 为1–600整数。后台循环短序列，到期提交停止；新序列替换旧序列。自由控制、经典控制、手动停止等控制会取消DIY。DIY没有暂停续播，原暂停／继续只用于经典模式。

主项目通过既有HTTP强度接口发送，每帧等到系统写入确认后再前进；状态检查不发送蓝牙查询。慢链路会拉长节奏，不补发追赶，运行时限仍到期提交停止。计时与HTTP请求存在延迟，不能保证准点物理停止。DIY运行期间拒绝电量／功能查询，避免替换当前帧确认记录；这是新增PC端DIY调度约定，不是原小程序流程。

此实现未改蓝牙字节、UUID或原厂经典播放器。直接通过正式服务8767入口发送控制会使主项目任务检测到指令被替换而结束，建议运行DIY时从主项目面板控制。后台任务只存在于主应用内存，不会在重启后自动恢复。

## 验证与部署边界

离线测试使用模拟服务与计时器，不连接真实硬件、不调用付费模型。部署需要重启主应用以加载本次接入；本次实现不自行重启正在使用的服务。实机节奏、供应商工具协议与浏览器交互需要用户在已验收的笔记本环境确认。主应用沿用现有访问控制，未新增公网认证；仅用于可信的本机或既有受保护部署。

# 独立情绪实验台

这是 WRX 项目中的独立前端实验，不接入聊天、Heartbeat、SQLite、角色或供应商，也不调用模型。今后的评论与修改以本目录为准，不依赖聊天中的临时可视化。

运行文件在根目录`experiments/emotion-lab/`，本说明在docs统一维护。

## 文件与打开方式

- `index.html`：新版独立成品，双击后可在普通浏览器打开。
- `emotion-lab.fragment.html`：新版可编辑源文件，也是聊天内预览的来源。
- `archive-v1.html`、`archive-v1.fragment.html`：原来 63 项版本的成品与源文件备份，保留用于比较。
- `test.cjs`：无需供应商和网络的模拟回归。

独立页面通过浏览器本地存储保存最近一次参数与数值；浏览器禁用本地存储、清理数据、更换浏览器或改变文件路径时，不保证恢复。源文件始终保存在项目内。旧版调参状态不会自动迁移到精简版，避免删减变量后错误映射。

## 新版范围与默认假设

六组各六项，共 36 个变量；Character 和 User 各一套。

| 分组 | 六项 |
|---|---|
| 关系与依恋 | 亲近、爱意、信任、依恋、思念、疏离 |
| 喜悦与探索 | 喜悦、兴奋、满足、期待、希望、好奇 |
| 担忧与压力 | 担忧、焦虑、恐惧、不安、压力、内疚 |
| 愤怒与防御 | 生气、委屈、受伤、防备、悔恨、嫉妒 |
| 低落与退缩 | 悲伤、沮丧、退缩、孤独、空虚、无聊 |
| 身心与欲望 | 精力、疲惫、陪伴欲、倾诉欲、探索欲、亲昵欲 |

每组六维雷达叠加 Character 实线与 User 虚线。点击变量可以修改强度、程度、常态、变化率、回归时间和状态有效期；紫色 ◆ 标识设计假设。

默认联系阈值 60、冷却 2 小时、User 情绪影响倍数 1、Character 退缩影响倍数 1。状态默认持续 2 小时；部分情境使用 3–8 小时。所有参数均为模拟体验假设，不代表心理学结论。各变量初值、回归时间和系数的完整默认表在源文件 `groups` 中。

## 情绪公式

- x：当前强度，0–100。
- b：常态值，0–100。
- d：状态推动程度，−5 到 +5。
- g：每一级状态推动的每小时变化量。
- r：常规每小时变化量。
- H：无状态推动、无常规变化时消除约 95% 偏离所需小时数。

```text
每小时变化 = r + g × d + (3 / H) × (b − x)
```

状态为正不保证最终数值上升：例如担忧 x=65、b=10、d=+2、g=5、H=6、r=0，状态推动是 +10，回归力是 −27.5，净变化为 −17.5/小时。界面显示的“上升”代表状态推动的方向，实际净变化在编辑区另列。

实际推进使用指数解，避免更新频率改变结果：

```text
k = 3 / H
q = b + (r + g × d) / k
x_new = clamp(q + (x_old − q) × exp(−k × Δ小时), 0, 100)
```

状态到期时拆分计算并将 d 置零。r 不为零时，长期平衡点是 b+r/k，不能声称会严格回到 b。每次最多推进 5 分钟的小步，用于检查状态到期、动机触发及联系冷却；情绪演算本身使用指数解。

## 动机公式

以下未标 User 的变量均来自 Character。U 为用户情绪影响倍数，R 为退缩影响倍数。

```text
退缩合力 = R × (0.25悲伤 + 0.30退缩 + 0.20生气 + 0.15疲惫)

靠近加分 = 0.45思念 + 0.25依恋 + 0.20陪伴欲 + 0.15爱意 + 0.10亲昵欲
靠近减分 = 退缩合力 + 0.30疏离

安抚加分 = U × (0.40User生气 + 0.45User悲伤 + 0.30User焦虑 + 0.20User委屈)
         + 0.35担忧 + 0.15爱意
安抚减分 = 退缩合力 + 0.15防备

修复加分 = 0.50悔恨 + 0.35内疚 + 0.20爱意 + 0.15U × User受伤
修复减分 = R × (0.40生气 + 0.30防备 + 0.20委屈)

分享加分 = 0.35喜悦 + 0.30兴奋 + 0.25倾诉欲 + 0.20探索欲 + 0.15好奇
分享减分 = R × (0.30疲惫 + 0.30退缩 + 0.20悲伤)

每个动机分数 = clamp(加分 − 减分, 0, 100)
```

选最高动机，达到联系阈值且冷却、安静期结束，才模拟唤醒。模拟联系会减少 Character 思念与倾诉欲各 25，不解除 User 情绪；模型真实生成阶段尚未接入。

## 用户心情来源

没有 AI 推测。用户可以直接改值，或选一组六题自评：每题 0–4 分，强度=答案×25。只有完整填写当前组六题才应用，只修改该组六项，将状态程度归零；其他组保持原样。这是自评输入方式，不是经验证的心理测评量表。

User 初始未填写项用 0，精力 65、疲惫 20 为演示初值。评分默认不随时间变化。只有明确打开“允许 User 评分随模拟时间变化”，才使用同样的状态演算；或者明确勾选“应用情境时填入示例 User 评分”，由情境按钮填入演示值。

## 修改与验证

先改 `emotion-lab.fragment.html`，执行：

```powershell
node experiments/emotion-lab/test.cjs
```

成品index.html内嵌样式和脚本，可离线打开。修改fragment后需用可用的渲染／导出工具同步成品，单独跑test.cjs不会重建index.html；不再依赖某个客户端插件的固定缓存路径。实验反馈可以在同一聊天继续描述，后续统一修改本目录源文件。尚未做实际浏览器视觉验收；自动验证包含六组结构、雷达节点、情绪演算、问卷校验、用户评分保持、情境、冷却、冲突和保存恢复。

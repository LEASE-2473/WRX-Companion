# 当前版本使用与验收

## 启动与配置

双击根目录 `start_companion.bat`，打开 http://127.0.0.1:2473 。这是本机服务，未部署云端。

1. 左下「模型与语音」配置并保存 LLM 的 Base URL、Key、Model；文字聊天无需 STT 和 TTS。
2. 「角色设定」新建／复制角色，填写人格、背景、关系、风格、用户称呼与 Persona，可绑定预设、世界书、LLM 和默认 TTS。未绑定时跟随当前全局选择。
3. 切换侧栏角色，再新建对话；不同角色会话隔离。消息由后端自动保存，Enter 发送、Shift + Enter 换行，Ctrl + Enter 也可发送。
4. 预设和世界书沿用已有编辑／导入能力。Character 与 Persona 分别通过 `charDefinitions`、`userDefinitions` Marker 注入，历史需要启用 `chatHistory`。上下文条数仅限制本轮输入，不删除聊天。

## 角色情绪宏与消息顺序

默认发送顺序：固定情绪规则（system）→聊天历史→当前状态与服务器时间（合并为D1 system）→本轮实际消息／图片（D0 user）。用户正文不附加时间或内部情绪内容。预设尾部自检与联网资料保留各自角色，排在本轮user之前；默认状态／时间保持紧邻user。旧Depth=0注入也会放到user前，不能占据真实D0。

- `{{char_status_rules}}`：角色状态设置中的聊天情绪提示词、数值更新协议及沉默约定；默认在Chat History前。
- `{{char_status}}`：当前角色情绪快照；默认在D1 system。
- `{{current_time}}`：本轮服务器时间和时区；默认与当前状态合并为D1 system。

在预设中新增普通条目，Role选system，Content填写宏。固定规则用Relative并拖到Chat History前；状态／时间用In-Chat、Depth=1，建议写在同一条目。保存后下一轮生效。实际启用展开后取消对应默认注入；禁用条目仍使用默认位置；显式多次使用宏按配置重复展开。宏仍可自由定位，手动前置动态值会影响后续前缀缓存。上下文调试可预览最终结果，不调用模型。

## 消息操作与语音

AI 回复下显示 Input / Cache / Output。没有真实供应商字段则为 `—`，不会将估算冒充账单。展开「用量明细」可查看回复和 AUTO 搜索判断的额外调用。

用户消息的时间位于气泡外，底部默认显示“编辑”和“编辑并重新生成”，直接在气泡内修改正文、保存或取消。“编辑”只保存文字、不调用模型、不改变旧回复；“更多”提供带符号的复制正文与开分支，取消用户编辑后分支发送。原地重发成功才替换原用户正文及紧随AI回复，保留ID、图片及后续聊天；失败或停止保留原文。后续消息不会自动重写；若修改会改变后续语义，可选新分支。末尾失败消息也可原地重发。AI回复支持原地重新生成，也可重新生成到分支；分支保留原对话和旧回复，并显示返回原对话入口。手动编辑 AI 文本没有新的 LLM usage。分支默认不开启 Heartbeat。

配置 TTS 后点击回复下「朗读」生成并播放，播放中再点可停止；「音色」可选本次朗读 Profile。角色设定可保存默认音色。复用 WRX 的 HTTP／豆包 WebSocket 协议，朗读不重新请求 LLM、不改正文。真实复刻音色仍需实际服务联调。

「麦克风」打开语音弹窗，配置 STT、LLM、TTS 后按住按钮录音。语音进入当前会话的相同 Core；热键只在语音弹窗中启用，普通聊天不会因空格触发录音。

## 联网与主动联系

「联网搜索」支持 Tavily（Key）或启用 JSON 输出的 SearXNG（地址）。输入框下可选自动、强制、禁止搜索。AUTO 的模型判断可能另产生一次模型调用；搜索来源随回复保存，失败会明确提示。

「主动联系」针对当前会话启用 Heartbeat，设置间隔、互动后冷却、每日主动消息上限和静默时段。静默开始与结束相同时表示全天静默。立即检查也遵守这些限制。模型选择沉默时只记录检查；选择联系时写入正常 AI 消息，下次对话会包含该历史。

关页不停止后端任务，结束启动窗口／后端进程会停止调度。重新打开页面会读取后台保存的消息。**当前尚无 iPhone 系统弹窗、Web Push 或微信通道**，页面轮询不是系统推送。

## 离线验证与当前限制

运行 `.venv\Scripts\python.exe -m pytest -q` 执行隔离的模拟 API 检查。`tests/ui_preview.py` 在本机 2474 端口提供临时数据库和模拟模型／搜索／音色，只用于界面验收，不是正式聊天服务。

Memory 暂缓；原始聊天仍保存。云端部署、鉴权、手机通知、真实音色与麦克风验收尚未完成。此版本不应直接暴露到公网。

## 心跳自主判断（2026-10-02）

心跳不再设置情绪触发阈值。通过频率限制后，模型根据当前情绪、关系、聊天与记忆自行选择联系或沉默。普通对话的允许沉默开关不限制心跳。两次主动判断最小间隔、静默时段、互动冷却与每日消息上限仍生效。模型只依据明确资料考虑用户作息，不从时间推断用户活动。每次有效心跳即使最终沉默也会产生模型用量。
